## 1. 注册并加入队伍

注册账号后，进入「找队友」。可以创建队伍，也可以点击一个队伍发出加入申请，由队长接受或拒绝。右上角通知中可以接受别人发来的邀请。每队最多三人，单人参赛也需要创建队伍。

## 2. 准备完整项目

项目语言不限，读取当前观测数据后逐轮返回决策，不强制调用模型。接口说明和示例项目见[文档](/docs)。

## 3. 提交完整项目

显著位置的「提交」按钮统一进入[参赛](/compete)。填写公开仓库链接或上传私有 ZIP，审阅源码版本、启动设置和提出的接口文件，再确认用于评测的版本。不接受 CSV。

模型调用可选，需要时请自备 API 和额度。凭证加密传输，只在本次运行内存中使用，不写入数据库、文件或日志。不要把密钥放进项目。

使用模型时，需要在「参赛」页填写支持 HTTPS 的接口、模型和密钥，并保持页面打开（包括自动适配期间）。关闭页面或断开连接会清除密钥，重新连接需再次填写。

## 4. 评测并查看结果

每批评测覆盖全部指定场景，每次新评测使用新的保密随机种子。平台先记录本轮决策，再发放下一轮观测。固定参考算法检查题目难度并用于分数校准。

结果包含校准后的上榜分、原始得分组成和运行记录。全部场景完成后才上榜；实时榜显示每队最高分的完整批次，仅为初步成绩。10 月 8 日（UTC+8）每队开始一次最终评测，平台依次运行 3 批全新题目，平均分决定名次，详见[规则](/rules)。

下载结果可以查看每次决策和运行失败原因。运行时限与 API 额度以参赛页显示为准。评测无法完成时，可通过[公告](/announcements)联系主办方。
